# C20 — information et accord pour la régie

Livré le 23/10/2026 : regie-textes.md, affiche courte, demande interne à la direction et fiche Game Master de dix consignes. Les caractéristiques matérielles, lieux exacts, dates, responsables et modalités d’accord restent vierges. Aucun équipement réel ni autorisation n’est supposé.

Sources : SUIVI.md, C20 ; brief §7.10 et question 11. Il s’agit d’une proposition d’organisation à faire valider par l’établissement, sans conclusion juridique ni prétention de constituer toutes les autorisations nécessaires. Le nom du responsable se complète seulement dans le document opérationnel, hors dépôt public. Ne pas diffuser le modèle rempli dans le dépôt.

L’affiche affirme les règles prévues : direct local, aucun enregistrement, aucun envoi. Avant son usage, vérifier que la régie les respecte effectivement ; sinon ne pas activer les caméras. Le modèle exclut un flux sur un autre poste à travers le réseau tant que le cadrage « rien n’est envoyé » reste celui demandé. Aucun bouton de régie existant n’est inventé : son libellé se complète après livraison. Le refus déclenche l’arrêt de toutes les caméras et l’appel du professeur ; la solution sans caméra doit être préparée.

Étape 12 toujours conditionnelle. Aucun courrier envoyé, accord demandé ou caméra activée. Aucun fichier du site modifié.
