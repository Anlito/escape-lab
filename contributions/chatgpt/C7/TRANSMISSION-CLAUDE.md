# C7 — messages des jalons et contrôles

Livré le 23/10/2026 : messages.js, quatorze jalons avec quatre états chacun et dix-sept contrôles. Identifiants repris à l’identique de site/donnees/jalons.js et de SUIVI.md. Chaque message contient au plus quinze mots ; le groupe est tutoyé.

Les textes ne calculent ni état ni retard. Les messages « fait » de câblage, M1, M2 et M3 supposent une validation réelle du professeur ; ne pas les afficher sur la seule déclaration « prêt » du groupe. Les contrôles décrivent une action, sans code matériel ni valeur électrique. Pour les contrôles électriques, ils renvoient au professeur ; le contrôle masse commune demande une vérification selon le montage plutôt qu’un raccordement automatique. Aucun avertissement ne remplace la validation. Les photos concernent les réalisations, sans élève reconnaissable.

Le texte sur les durées vise le dépassement du temps total de l’équipe, pas la seule estimation d’une énigme. Un champ de lien matière court appelle une précision ; le nombre de caractères ne prouve pas sa qualité. Le programme « qui fonctionne » suppose des essais, pas seulement un fichier enregistré. Les indices sont complets seulement si les trois niveaux et leurs trois phrases talkie sont renseignés.
