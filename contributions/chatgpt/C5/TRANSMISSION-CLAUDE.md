# C5 — textes d’aide

Livré le 23/10/2026 : aides.js, 42 entrées, trois textes par entrée, au format demandé. Scripts classiques, aucun module ni dépendance. Chaque phrase contient au plus quinze mots.

Convention d’identifiants : histoire.* et liaison.* pour les éléments partagés ; enigme.*, fonctionnement, indices.*, installation.* et journal pour les champs du groupe ; jourJ.* pour les rôles et le planning. Pour un indice, indices.n1/n2/n3 aide le sous-champ texte ; indices.n1.talkie, etc., aide le sous-champ talkie. Un chemin jourJ.* désigne le champ du modèle, pas le nom physique de la collection jourj. Claude adaptera ces identifiants si nécessaire.

Les exemples reprennent 3Z9 : station Aurore, cinq postes, fragments du protocole, grille et personnages fictifs. Les exemples de remise à zéro et de jour J sont des prolongements pédagogiques proposés, pas des données déjà enregistrées dans la démo. Le champ solution reste explicitement à compléter : aucune réponse ni aucun code réel n’est fourni.

Sources : brief §§7.3, 7.4, 7.6, 7.9 et annexe B ; site/donnees/demo.js et exemples d’indices de C1 intégrés. À relire par Thomas ; aucun écran modifié.
